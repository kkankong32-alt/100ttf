# 출처와 사용 범위

- 신규 원화: 이 작업의 Codex 내장 imagegen으로 생성. 별도 유료 모델/API/외부 유료 에셋 구매 없음. `originals/`와 `production/prompts*.json`에 기록. AI 출력에 임의 CC0 라이선스를 붙이지 않는다.
- 재사용 원화: 사용자가 보유한 schoolfront-pack-v1, choice-variants-animation-v1, century-change-v1, npc-environment-v3-v1. 원본 해시와 경로는 manifest 및 reference/existing_assets.json. 원본 패키지의 권리/출처 조건을 승계한다.
- Phaser: 기존 프로젝트 vendor 파일 재사용, MIT. qa/vendor/PHASER-LICENSE.md 포함.
- 검수 이미지 한글: 시스템 Malgun Gothic로 래스터화. 폰트 파일을 배포하지 않는다. 본편 텍스트에는 기존 프로젝트의 허용된 폰트를 사용한다.
- 제작: Pillow/NumPy 기반 크롭·알파 정리·레이어 분해·그림자·2D 리깅·조합. UI 피드백 선/화살표는 코드 원본 포함. 생성 이미지를 그대로 애니메이션이라고 등록하지 않았다.
